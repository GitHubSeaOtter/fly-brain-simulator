# FLY / Brain Lab

iPhone Safari向け3Dハエ行動シミュレーターの第1段階。依存パッケージ不要のWebGL 1製レンダラーと、軽量な感覚・行動モデルで端末性能を調べます。

## 起動

```sh
python3 -m http.server 5173
```

ブラウザで `http://localhost:5173` を開きます。iPhoneで確認する場合は、HTTPSで配信するか、同じWi-Fi上の開発機のアドレスを開いてください。GitHub Pagesを利用する場合はリポジトリ設定の Pages で `main` / `/ (root)` を選択します。公開前にアクセス範囲を確認してください。

## 計測

画面で脳計算負荷（256〜32,768の**合成計算要素**）と描画解像度を選び、少なくとも10秒動作させてからCSVを保存します。FPS、描画CPU時間、脳計算CPU時間、更新回数を記録します。描画CPU時間はGPU実行完了までの時間ではありません。画面を閉じたときやバックグラウンドになったときの計測は除外します。固定更新30 Hz、描画は画面更新に合わせ、極端な遅延時は更新を間引きます。

`npm test` で行動と合成負荷の独立性を確認できます。

## 学習比較

「4種類を比較する」で、人工的な匂い8入力からエサの位置（左/右）を推定する連想学習を開始します。256 / 2,048 / 8,192 / 32,768個のランダムな非線形特徴と学習可能な出力重みを使用します。入力に接続する特徴の乱数列は共通で、小さいモデルの特徴は大きいモデルの先頭と一致します。全モデルで同じ512問、同じ順番、4周の訓練を行います。別の乱数種で作った256問は訓練には使わず、訓練前後の正答率を測ります。偶然の片寄りがあるため、基準は各行の訓練前正答率です。

専用Web Workerで計算するため、3D画面の操作を保てます。表は訓練前後の正答率、改善幅、訓練時間を示します。CSVには正答率、訓練時間、評価時間、乱数種、入力数、OSのuser agentを残します。訓練時間は端末での経過時間で、端末間比較は同一条件で行ってください。実行中の描画FPSと計算負荷は互いに影響する可能性があります。

この学習課題はゲーム用の人工ルールです。3Dハエの操作にはまだ接続していません。特徴の数は脳のニューロン数ではなく、実際のハエの学習を再現したと解釈できません。学習後の重みも現段階では保存しません。

## モデルの境界

これは行動モデルを持つ3D試作です。実際のFlyWireコネクトームや神経細胞モデルは未導入です。計算要素数は端末負荷の指標であり、神経細胞数ではありません。FlyWireは成体雌ショウジョウバエの139,255ニューロン、約5,450万シナプスの接続図を報告していますが、接続図だけで行動が決まるわけではありません。研究用の全脳LIFモデルと、身体・環境の結合は別の実装段階です。

参考（2026-09-23確認）：[FlyWire connectome, Nature 2024](https://www.nature.com/articles/s41586-024-07558-y) / [sensorimotor model, Nature 2024](https://www.nature.com/articles/s41586-024-07763-9) / [whole-body simulation, Nature 2025](https://www.nature.com/articles/s41586-025-09029-4)。

## 次の段階

1. iPhoneの機種・SafariバージョンごとのCSVを比較し、描画解像度と計算量の予算を決める。
2. 実データ導入の前に、使用データ、ライセンス、ニューロンの入力と出力、必要メモリ・計算量を設計する。
3. 名前・色・育成状態をバージョン付きJSONとして保存し、入力検証とサイズ制限を実装する。
4. エサ争奪のルールと刺激技、再現可能な乱数と対戦ログを定義し、他人のデータを読み込む非同期対戦を実装する。
5. アップロード機能は認証、保存先、公開範囲、削除方法を決めてから追加する。
